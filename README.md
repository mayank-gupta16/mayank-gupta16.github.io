# Mayank Gupta — Freelance portfolio

Personal portfolio for backend development, data engineering, and applied AI.

Live website: https://mayank-gupta16.github.io/

## Updating the site

Edit `index.html` for copy, projects, contact information, and links. Edit `styles.css` for design and `script.js` for navigation, email copy, and enquiry draft behavior. Push changes to `main`; GitHub Pages publishes from the repository root.

This is a static site. No package installation, framework build, database, or API keys are required. Serve the folder with any local HTTP server to preview changes.

## Contact behavior

The enquiry form prepares a `mailto:` draft. It does not send or store messages. Visitors review and send using their own email application. A direct email link and copy-address button provide alternatives. GitHub and LinkedIn links use the profile information supplied for this portfolio.

## Accessibility and assets

Semantic sections, keyboard-accessible project disclosures, a skip link, visible focus styles, responsive navigation, and reduced-motion support are included. Core content and project disclosures work without JavaScript. Contact draft generation and the copy button require JavaScript.

The Manrope font is self-hosted under the SIL Open Font License; see `assets/OFL-Manrope.txt`. All other visual elements are local HTML, CSS, and SVG diagrams. The site has no analytics, tracking scripts, external fonts, or third-party runtime requests.

## Hosting

GitHub Pages publishes the `main` branch root with HTTPS. `.nojekyll` preserves static assets. `404.html`, `robots.txt`, canonical metadata, and `sitemap.xml` use the root user-site address. Update those addresses if a custom domain is added later.
